# TCLA practice interview question bank

Source: user-supplied **TCLA’s Practice Interview Question Bank**, 10 pages. The original PDF is not distributed in this repository. This third-party reference material is not covered by the application code license; see [third-party notices](THIRD_PARTY_NOTICES.md).

Extracted on 28 September 2026. The source contains **200 numbered entries plus one unnumbered question**, giving **201 entries** in this Markdown copy. Some entries contain multiple questions or follow-ups. The unnumbered spare-time question between 17 and 18 is labelled **17a** here for reference; the PDF's original numbering is otherwise preserved.

Question wording, categories, placeholders, repetitions and source notes are retained. Only line wrapping and whitespace have been normalised. Source grammatical errors are not silently rewritten. Page references refer to the original PDF.

This is a general interview bank, not a claim that all questions occur in one-way video interviews. Several technical questions require a case study, and several prompts depend on the candidate's history, a named firm or current information.

## How to use this bank in practice

The following are our suggested operating rules, not additional TCLA source questions:

- Pick a category, then select a random question within it.
- Use 30–60 seconds of preparation and 60, 90 or 120 seconds for the answer, following the written practice advice. Match a firm's actual timing when known.
- Substitute firm, city, sector and year placeholders before the timed attempt.
- Keep related follow-ups together: for example 15–16 and 142–143. Entry 167 contains its own follow-up.
- Mark personal-history questions as applicable only when that premise is true for the candidate.
- Refresh time-sensitive premises before practising: especially the exchange-rate question (139), the falling oil/gas share-price premise (142–143), and questions about current news, technology, clients or market conditions. The source's wording is not confirmation that its premise is true today.
- Supply the case facts for questions about a target company, litigation, a payment or an acquisition. The PDF provides prompts, not the underlying case materials or model answers.
- Keep source numbering in a practice log so answers and feedback can be traced back to this bank.
